# User Management System – Spring Boot REST API

A beginner-friendly CRUD REST API built with Java 17, Spring Boot, Spring Web, Spring Data JPA, Hibernate and MySQL.

## Requirements
- JDK 17 or later
- Maven (or use the included Maven Wrapper if generated by your IDE)
- MySQL Server
- Postman (optional, for API testing)

## Setup
1. Create the database:
   ```sql
   CREATE DATABASE user_management;
   ```
2. Open `src/main/resources/application.properties`.
3. Change `spring.datasource.username` and `spring.datasource.password` to match your MySQL credentials.
4. From the project root, run:
   ```bash
   mvn spring-boot:run
   ```
   Or build and run:
   ```bash
   mvn clean package
   java -jar target/usermanagement-0.0.1-SNAPSHOT.jar
   ```
5. The API runs at `http://localhost:8080`.

Hibernate creates or updates the `users` table automatically (`ddl-auto=update`).

## API endpoints

Base URL: `http://localhost:8080/api/users`

| Method | Endpoint | Purpose | Success |
|---|---|---|---|
| POST | `/api/users` | Create a user | 201 Created |
| GET | `/api/users` | List all users | 200 OK |
| GET | `/api/users/{id}` | Get one user | 200 OK |
| PUT | `/api/users/{id}` | Update a user | 200 OK |
| DELETE | `/api/users/{id}` | Delete a user | 204 No Content |

### Example JSON body
Use `Content-Type: application/json`:
```json
{
  "name": "Jeeva",
  "email": "jeeva@example.com",
  "phone": "9876543210"
}
```

For POST and PUT, send all three fields. Email addresses must be valid and unique.

## Error responses
- `400 Bad Request`: validation failed
- `404 Not Found`: requested user ID does not exist
- `409 Conflict`: email already exists
- `500 Internal Server Error`: unexpected server error

## Postman
Import `postman/UserManagementAPI.postman_collection.json` into Postman. Run requests in order; create a user first to test the other endpoints. The collection uses a `baseUrl` variable and a sample ID of `1`.
